# Instruções do projeto

- Escrever mensagens e documentação em português do Brasil.
- Este projeto mantém os atalhos pessoais de Leonardo para macOS com Karabiner-Elements.
- A regra versionada está em `atalhos-windows-karabiner.json`. Ela é uma regra individual para Complex Modifications.
- Preservar os atalhos existentes ao adicionar alterações solicitadas.
- Usar Control esquerdo e direito por meio do modificador genérico `control`.
- Ctrl+Y apaga a linha atual por preferência expressa do usuário.
- Preservar outras regras e perfis ao aplicar a configuração ao Karabiner.
- Antes de alterar a configuração instalada, criar uma cópia de segurança.
- Validar a sintaxe JSON e a ausência de entradas `from` duplicadas. Testar mudanças de comportamento em texto temporário e registrar limitações.
- A configuração inicial foi exportada do perfil ativo. Os testes funcionais em aplicativos ainda estão pendentes.
- Manter as instruções compartilhadas em AGENTS.md. Recursos complementares futuros ficam em .agents/ e devem ser listados aqui.
